# 墨布 Markdown 语法

当前规则来自墨布项目 `src/main.jsx` 的 `SYNTAX_RULES` 与渲染器。生成内容仅使用编辑器确认支持的结构。

所有语法都遵守 [内容感知排版](content-aware-layout.md)：有明确语义依据才使用，并从全文检查密度、相邻关系和视觉层级。不要为了覆盖语法类型或增加装饰而添加任何标记；普通正文是默认且有效的样式。

| 语义 | 写法 | 约束 |
| --- | --- | --- |
| 主标题 | `# 标题` | 全文一个 |
| 副标题 | `@subtitle 副标题` | 最多一个，紧跟主标题 |
| 二级标题 | `## 章节标题` | 章节级 |
| 三级标题 | `### 小节标题` | 必须隶属于二级标题 |
| 粗体 | `**需要加粗的内容**` | 段内关键词 |
| 斜体 | `*内容*` | 克制使用 |
| 行内重点 | `{{highlight:关键词}}` | 在段内突出关键词、关键数值或短语；内容不要换行 |
| 独立重点块 | `{{highlight:核心判断}}` | 独立成段，用于完整核心判断 |
| 行内引用 | `{{quote:引用短句}}` | 在原句位置标记真实短句引用 |
| 引用 | `> 引用内容` | 一行一个引用段 |
| 项目列表 | `- 列表项目` | 同组格式一致 |
| 编号列表 | `1. 列表项目` | 使用普通 Markdown 编号 |
| 表格 | GFM 管道表格 | 必须有表头和分隔行 |
| 图片 | `![图片说明](相对路径)` | 独占一行；路径指向同包图片 |
| 手动换行 | `<br>` | 只在标题等确需断行处使用 |
| 分割线 | `---` | 独占一行 |
| 链接 | `[文字](https://地址)` | 保留有效 URL |
| 行内代码 | `` `代码` `` | 技术名词或命令 |
| 代码块 | 三反引号围栏 | 可带语言标识 |

## 墨布专用规则

- `@subtitle` 与 `{{highlight:...}}` 是墨布专用语法，不要退化成 blockquote 或单独粗体。
- 不主动新增 `{{subtitle:...}}`、`{{h2:...}}`、`{{h3:...}}` 三种行内标题样式；原文已有时保留，用户明确指定时才新增。`@subtitle`、`##`、`###` 仍按文章结构正常识别。
- 根据上下文主动选择 `{{highlight:关键词}}` 突出关键词、`{{quote:引用短句}}` 标记真实短句引用。两者保持原句位置，不加换行、不改写文字，不与其他强调样式嵌套或重复叠加。
- 单独一段的 `{{highlight:核心判断}}` 是独立重点块，应与段内关键词强调分开判断；整段引用使用 `> 引语`。
- 图片 alt 与路径都不要含换行。为兼容预览和复制，文件名避免空格、圆括号、`#`、`?`、`%`。
- 段落之间保留一个空行。标题、副标题、图片、引用、列表、表格、分割线和代码块前后保留空行。

## 最小骨架

```markdown
# 主标题

@subtitle 副标题

![头图说明](文章名-图片/文章名-头图-01-主题.png)

导语正文。

{{highlight:全篇最值得摘录的核心判断。}}

## 第一部分

正文。

### 小节

正文。

> 原文中的引用。

![插图说明](文章名-图片/文章名-插图-01-主题.png)
```
